# PowerMaxx Electric Website

Upload the contents of this folder to Netlify as a static site.

## Netlify Drag And Drop

1. Open Netlify.
2. Add a new site by manual deploy.
3. Drag this entire powermaxx-electric-site folder into the upload area.
4. Add powermaxxelectric.com as the custom domain.
5. Update the domain DNS records using the values Netlify gives you.

## Main Files

- index.html is the website.
- styles.css controls the layout and colour scheme.
- script.js powers the quote email form.
- assets/ contains the PowerMaxx logo and icon files.
