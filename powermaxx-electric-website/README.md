# PowerMaxx Electric Website

Static website for **powermaxxelectric.com**.

## Files

- `index.html` — homepage
- `styles.css` — site design
- `script.js` — quote form and header behavior
- `robots.txt` — crawler rules
- `sitemap.xml` — search-engine sitemap
- `_headers` — Netlify security and caching headers
- `assets/` — PowerMaxx logos and icon

## Netlify deployment

This project does not require a build command.

- Build command: leave blank
- Publish directory: `/` or leave blank
- Primary domain: `powermaxxelectric.com`
- Redirect `www.powermaxxelectric.com` to the primary domain

## Development workflow

Use a development branch for SEO and content changes, preview it in Netlify, and merge only after review.
