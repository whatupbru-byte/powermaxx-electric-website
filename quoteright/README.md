# QuoteRight MVP

A mobile-first estimating calculator designed as the first version of a future SaaS product for contractors and small businesses.

## Current MVP
- Free materials + labour + markup + tax calculator
- Print/save estimate via browser print dialog
- Responsive landing page
- Pro pricing/feature preview

## Monetization roadmap
1. Free SEO calculators to acquire traffic.
2. Accounts + saved projects.
3. Paid Pro subscription around CAD $9.99/month.
4. Branded PDF quotes and customer records.
5. Relevant affiliate partnerships after traffic is established.

## Deploy
This folder is a static site and can be deployed by setting the Netlify publish directory to `quoteright` with no build command.

For a standalone production repository, copy the `quoteright` directory into its own repo before connecting a custom domain.
